# RUBICEzy

A Rubik's cube solver web app. Paint your real cube onto the on-screen cube and get step-by-step solve instructions from a self-verifying solver engine.

- Sub-5ms solutions, tested 30+ times with a 100% success rate
- Draggable 3D cube, 54-sticker flat map, random scramble flow
- Eight beginner solving phases with turn-by-turn plain-language guidance
- Playback controls with speed adjustment, Engine & maths panel

Live: https://vaibhavtiwariz.github.io/rubicezy/
